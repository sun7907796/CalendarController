使用說明

      

        
功能總覽

        
    
          
  • 月曆檢視，可切換上/下個月、回到今天。
    • 
          
  • 新增／編輯／刪除事件（標題、日期、全天、起訖時間、地點、說明）。
    • 
          
  • 事件存於本機，離線也能編輯。
    • 
          
  • 與 Google 日曆雙向同步：本機事件推送到 Google、Google 事件拉回本機。
    • 
          
  • 淺藍＝僅本機；淺綠＝已與 Google 同步。
    • 
        


        
日常操作

        

          
新增事件點月曆上任一天的空白處

          
編輯事件點月曆上的事件方塊

          
刪除事件開啟事件 → 按「刪除」（已同步者會一併從 Google 刪除）

          
全天事件編輯視窗勾選「全天」

          
切換月份左上角 ‹ / ›，或按「今天」

          
同步 Google右上角「同步」按鈕

        


        
設定 Google 同步（一次性）

        
同步需要你自己的 Google API 憑證（免費）：

        
    
          
  1. 到 Google Cloud Console 建立專案，於「API 和服務 → 程式庫」啟用 Google Calendar API。
    2. 
          
  2. 在「OAuth 同意畫面」選「外部」，並把自己的 Google 帳號加入「測試使用者」。
    3. 
          
  3. 在「憑證 → 建立憑證 → OAuth 用戶端 ID」，類型選 桌面應用程式，下載 JSON。
    4. 
          
  4. 回到本工具：按 匯入憑證 選擇該 JSON → 按 登入 Google → 在瀏覽器完成授權。
    5. 
          
  5. 狀態列顯示「Google：已連線」即完成，之後按 同步 即可。
    6. 
        

        
若瀏覽器顯示「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」即可，因為這是你自己建立的私人應用程式。


        
同步說明

        
    
          
  • 登入後，工具列會出現 日曆選單，可選擇要同步的 Google 日曆（如「本人／家庭…」）。選擇會被記住。
    • 
          
  • 按「同步」會處理目前檢視月份的前後各一個月範圍。
    • 
          
  • 順序：先把本機事件推送到 Google，再把該範圍的 Google 事件拉回本機。
    • 
          
  • 新事件會加入目前選定的日曆；已同步的事件則維持在它原本所屬的日曆更新。
    • 
          
  • 拉取只做新增與更新，不會刪除你 Google 上原有的行程。
    • 
        


        
資料存放位置

        
所有資料存在下列資料夾（不會上傳）：

        
%AppData%\calendar-controller\
├─ events.json        本機事件
├─ credentials.json   Google 憑證
└─ token.json         Google 授權權杖

        

        
重設 Google 連線：按「登出」；更換 Google 專案：重新「匯入憑證」即可。


        
其他

        
    
          
  • 點視窗右上角的 ✕ 不會結束程式，而是縮小到系統匣（右下角圖示）；在系統匣圖示按右鍵可「開啟主視窗」或「結束」。
    • 
          
  • 勾選底部的 「開機時自動啟動」，登入 Windows 後會自動於背景開啟本工具。
    • 
        


        
常見問題

        
    
          
  • 登入沒反應？ 先確認已「匯入憑證」，且憑證類型為「桌面應用程式」（不可選 Web 應用程式）。
    • 
          
  • 顯示「存取遭封鎖：尚未驗證」？ 請把你的帳號加入 OAuth 同意畫面的「測試使用者」。
    • 
          
  • Google 看不到事件？ 事件同步到「主要日曆（primary）」，請確認登入的是同一帳號。
